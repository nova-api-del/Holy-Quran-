# Holy Quran Auto Publisher

ينشئ Shorts/Reels قرآنية عمودية بأسلوبين بصريين يتناوب بينهما تلقائياً.

## أسلوب الفيديوهات
- **سينمائي:** الطبيعة والجبال والبحار والسماء والشروق والغروب والمساجد، بمشاهد هادئة متتابعة.
- **واقعي متنوع:** الحيوانات والطيور والحياة البرية والقطط والخيول والمشاهد الخارجية والحياة اليومية.
- يختار النظام أسلوباً واحداً لكل فيديو، ثم يبحث عن أربع لقطات متناسقة معه لتجنب خلط الأنماط داخل المقطع الواحد.
- يضيف الهوية النصية واسم القارئ، ويزامن المشاهد مع التلاوة.
- يحافظ على البحث عن التلاوات واختيار المقاطع وحدود الآيات كما هي دون تغيير.

## النشر
- ينشر Shorts على YouTube، وReels على Instagram عند توفر أسرار Cloudinary وMeta.
- مدة المقطع القصوى 58 ثانية.
- الجدولة مرتان يومياً: 12:00 ظهراً و20:00 مساءً بتوقيت العراق (UTC+3).
